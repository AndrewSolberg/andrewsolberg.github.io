How this applet works

A searchable index you can inspect

Import a catalog, enter ISBNs, or add a PDF. Build embeddings, then search for a topic. Select a book or expand its chapter list to inspect individual chapter scores and text.

Search fields

The fields are title, summary and contents, bibliography, index, subjects, and full text. Summary and table of contents form one text field with one joint embedding. Bibliography embeds the actual list of cited sources. A catalog note such as “includes bibliographical references” is not a citation list.

Older saved catalogs migrate contents into summary automatically. Changed summaries need indexing again; unchanged field embeddings are retained. Imports recognize descriptive summaries and preserve catalog citations separately.

Chapters and edited volumes

PDF outlines or detected chapter headings, catalog contents, and repository chapter records create nested chapter entries. Chapter titles alone can be indexed when no abstract or text is available. Known chapter authors, summaries, reference lists, and text are stored on each chapter. Select a chapter from the dropdown beneath its book, or use Add chapter to enter one manually. Chapters receive independent field embeddings and similarity scores and appear in comparison plots and CSV exports. Relative scores are scaled across all book and chapter entries.

Similarity scores

E5 small v2 produces normalized 384-dimensional vectors locally. Each field is split into text blocks; its vector is their normalized mean. A score is the query’s dot product with that vector. Composite is the weighted mean of available field scores. Set a field weight to zero to exclude it. Missing fields are excluded.

The model is designed for English. Similarity is not a probability. Relative similarity maps the catalog’s lowest score to 0 and highest to 1; tied scores map to 0.5. Each field scales independently, after the raw composite is calculated. Filters retain the catalog-wide ranges. Raw similarity shows the underlying dot products. Click headings to sort; use the Composite dropdown to change weights.

Two-query plot

Enter independent X and Y queries. Every book and chapter with paired composite scores is plotted. Query cosine compares the query vectors. The dashed regression line fits the entries currently shown using the selected raw or relative scale. A fit needs two paired entries and variation in X. Raw negative scores display at zero while regression uses their unclipped values.

Metadata pipeline

Add ISBNs queries Open Library and optionally the additional sources selected in Add PDF / metadata: Library of Congress, HathiTrust, Crossref, OAPEN, DOAB, BnF, Internet Archive, Google Books, WorldCat, DPLA, and Europeana. Lookups verify ISBN matches. Public catalog records can add subjects, summaries, contents, and chapter titles; actual cited sources are imported when supplied, including Crossref references.

Google Books, DPLA, and Europeana need API keys; WorldCat needs an eligible institutional subscription and an OAuth access token. Credentials stay in the current page session and are excluded from backups and saved applets. Per-source errors are reported while successful results remain available. Browser cross-origin restrictions can prevent a source from responding directly.

PDFs and review

PDF extraction and optional English OCR run on this device. Explicit abstract/summary sections and contents become the joint summary field. Bibliography, references, or works-cited sections supply cited-source text. Chapter page ranges are inferred from outlines or headings; review proposed chapters and fields before applying. Public Archive OCR text is optional; restricted files are skipped.

Rebuild embeddings after adding or editing text. Indexing works in bounded batches and retains completed blocks when paused.

Saving and importing

The browser saves your catalog and embeddings locally when storage is available. Export data creates a JSON backup. Save applet creates an HTML copy containing the catalog, chapters, and embeddings. Share a fresh empty copy when others should start their own library.

Import TSV, CSV, Excel, or JSON. Table imports need Book Id and Title; Bibliography, References, Cited Sources, and Works Cited columns are recognized. Contents is accepted on import and folded into summary. A JSON Chapters array can supply chapter metadata and text. Imports merge by Book Id, retain manual fields and unchanged embeddings, and preserve nested chapters. The app does not poll LibraryThing.

Deleting and privacy

Delete on a book removes it and its chapters after confirmation. Delete chapter removes only that chapter. Delete All clears this browser’s catalog, embeddings, categories, lookups, and saved queries. Downloaded applets, backups, and original PDFs remain on disk.

Book text, PDFs, and queries are processed locally. Runtime/model files download from jsDelivr and Hugging Face; Excel imports load SheetJS; PDF import loads PDF.js and optional Tesseract OCR. Enabled repositories receive selected ISBNs and the credentials required for their APIs.

If local file restrictions block downloads, serve the folder with python -m http.server 8765 --bind 127.0.0.1 and open http://127.0.0.1:8765/library_semantic_search.html.
